# The Sound of Influence: Identifying the Most Impactful Musician using Network Theory

This code uses Network Analysis to examine the relationships among musical artists to answer the question: Which artist was the most influential between 1960 and 2020, based on patterns of song covers and the prominence of their Wikipedia pages.

Scripts:  
The main analysis can be found in `analysis_whole.ipynb`. The other scripts contain data inspection, scraping and pre-processing.
